# Mini-Fantasy

Unity で制作したブラウザでプレイ可能な 3D アクション RPG です。

🎮 **[ブラウザでプレイする](https://shiny-sunset.github.io/Mini-Fantasy/)**

---

## 概要

プレイヤーを操作して敵を倒しながら進み、2 つの鍵を集めてボス部屋を目指すアクション RPG です。  
通常攻撃・魔法・ガード・必殺技を組み合わせてボスを撃破するのが目標です。

---

## 使用技術

| 項目 | 内容 |
|------|------|
| エンジン | Unity 6 (6000.3.17f1) |
| 言語 | C# |
| AI | NavMesh による経路探索 |
| カメラ | Cinemachine（ロックオン対応） |
| UI | TextMesh Pro |
| 物理 | Unity Physics（CharacterController / Rigidbody） |

---

## 実装した主な機能

- **プレイヤー**：移動・ダッシュ・通常攻撃・魔法・回復・ガード・必殺技（HP / MP / SP ゲージ管理）
- **敵 AI**：索敵・追跡・巡回の状態遷移（剣士・銃士・ボスの 3 種類）
- **ロックオンシステム**：Tab キーで近くの敵を順番にロックオン、専用カメラに切り替え
- **ボス戦**：距離に応じた近距離 / 遠距離攻撃の使い分け
- **ゲームフロー**：鍵収集 → ボス部屋解放 → ボス撃破 → クリア

---

## 操作方法

| 入力 | アクション |
|------|-----------|
| `W` `A` `S` `D` | 移動 |
| `Shift` + 移動 | ダッシュ |
| `Tab` | 近くの敵をロックオン |
| 左クリック | 通常攻撃 |
| 右クリック | 魔法攻撃 |
| `E` | 回復魔法 |
| `F` | ガード |
| `Q` | 必殺技（SP 満タン時） |
| `P` | ポーズ |

---

## ステータス

プレイヤーのステータスは左上に表示されています。

| ゲージ | 説明 |
|--------|------|
| 緑（HP） | 体力。0 になるとゲームオーバー |
| 青（MP） | 魔法使用に消費。時間で自動回復、通常攻撃でも回復 |
| ピンク（SP） | 必殺技に使用。満タンになると使用可能 |
