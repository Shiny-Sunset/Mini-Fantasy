# Mini-Fantasy

Unityで制作したブラウザプレイ可能なアクションRPGです。
[https://shiny-sunset.github.io/Mini-Fantasy/](https://shiny-sunset.github.io/Mini-Fantasy/)

## 遊び方

キャラクターを動かして、襲ってくる敵たちを倒しましょう！  
2つの鍵を探してボスの部屋を目指し、ボスを倒しましょう！

## ステータス表示

プレイヤーの各ステータスは左上に表示されています。

| ゲージ | 説明 |
|--------|------|
| 緑ゲージ（HP） | プレイヤーの体力 |
| 青ゲージ（MP） | 各魔法の使用に消費 |
| ピンクゲージ（SP） | 満タンになると必殺技を使用可能 |

## 操作方法

| 入力 | アクション |
|------|-----------|
| `W` `A` `S` `D` | 移動 |
| `Shift` + 移動 | ダッシュ |
| `Tab` | 近くの敵をロックオン |
| 左クリック | 通常攻撃 |
| 右クリック | 魔法攻撃 |
| `E` | 回復魔法 |
| `F` | ガード |
| `Q` | 必殺技（SP満タン時） |
| `P` | ポーズ |

## 開発者向け

ポーズ中の **Killボタン** を押すと、ステージ上の全敵をキルしてボス部屋のドアが開きます。
